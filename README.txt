PORTFOLIO CSS FILE

1. Keep style.css in the same folder as your HTML files.
2. Add this line inside the <head> section of each HTML file, below its <title>:
   <link rel="stylesheet" href="style.css">
3. Save the HTML files and refresh the website in your browser.

Files expected in the folder:
- index.html
- academic.html
- hobbies.html
- movies.html
- Contact.html
- style.css
